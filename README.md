# Product-Analytics-Dashborad
An interactive Power BI  dashboard for analyzing product performance and generating meaningful business insights

## Project Objectives

- Analyze product-related data.
- Identify trends and patterns.
- Understand product performance.
- Generate meaningful business insights.

## Tools & Technologies

- Microsoft Power BI
- Power Query
- Data Cleaning
- Data Visualization

## Key Features

- Interactive KPI cards.
- Dynamic filters and slicers.
- Product performance analysis.
- Interactive charts and visualizations.
- Business insights through data analysis.
